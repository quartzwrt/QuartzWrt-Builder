# QuartzWrt v0.2.4

**构建标识（build id）**：`v0.2.4`（设备侧 `/etc/quartz-build-id`，OTA 版本比较依据）
**基座**：ImmortalWrt 25.12 @ `3682a14dd5ec`
**Feed 锁定**：quartz @ `fee28c2cf5fe`；thirdparty @ `a399cb2779ef`；themes @ `4028440184a9`
**签名**：apk key id `6947a869aad621cb2a8c0765c39ea104`（稳定密钥，本地/CI 产物互认）
**本版目标**：x86_64 / Erya FNet3399（RK3399）/ Ariaboard Photonicat（RK3568）/ Hiveton H5000M（MT7987A）；**只出标准版**

## 本版变更

- **per-device OTA（按机型分发清单）**：同 subtarget 多机型不再共用一份镜像清单。
  - 设备端 `quartz-ota-update`（quartz-defaults `r7`）优先读取
    `ota/<target>/<device>.json`：设备名取 `/tmp/sysinfo/board_name`，逗号/空格归一为下划线
    （如 `erya,fnet-3399` → `erya_fnet-3399`）；文件不存在时回退共享清单；清单 `target`
    与本机不符直接拒绝升级。
  - 选镜像时优先匹配本机 device token，即使回退到共享清单也不会跨机型误刷。
  - 发布端 `publish-feed.sh` 按 sysupgrade 文件名中的机型 token 逐机型生成清单；同 subtarget
    多机型时共享清单 `images` 置空（旧客户端安全失败，不会拿错镜像）；单机型共享清单保留全量
    （兼容旧客户端）。
  - 在线复核新增 `check-feed-live.sh --ota-devices` 与官网 `verify.sh` per-device 验签。
- **rockchip/armv8 OTA 恢复**：FNet3399 与 Photonicat 各自命中自己的清单；v0.2.3 曾因无法区分
  机型而将该 target 的 OTA 清单置空。
- **其余内容与 v0.2.3 相同**（累积）：三 Feed（quartz / thirdparty / themes）、menuconfig 三层、
  Wi-Fi 驱动家族 meta、可选包 `quartz-docker`、Dashboard 主题门控、qmodem `quartz3`（上游
  `550ea99` 合并）。

## 使用注意

- **从 v0.2.3 升级到 v0.2.4**：
  - x86_64、H5000M：`quartz-ota-update --check` → `--apply` 可直接升级（共享清单全量）。
  - FNet3399 / Photonicat：v0.2.3 及更早的 OTA 客户端不认识 per-device 清单，而共享清单为
    空（安全设计），因此**需手动下载本 Release 对应镜像刷写一次**；从 v0.2.4 起后续版本可在
    设备上直接 OTA。
- **docker**：标准版不含 docker；`apk update && apk add quartz-docker` 安装。
- **主题**：软件源可选装 Vantage / 7Dollar / Aurora；安装 Vantage 后 Dashboard 自动切换为
  Vantage 版本，切回 Quartz 主题即恢复。
- 软件源 / OTA 只发标准版；OTA/刷机后 rootfs 不保留可选包，需要时重新安装。

## 升级

- 固件 OTA（v0.2.4 设备）：`quartz-ota-update --check` → `quartz-ota-update --apply`
  （清单 usign 验签 → 镜像 sha256 → `sysupgrade` 预检）。
- 手动刷写：x86 解压后写盘（EFI 机器用 `-efi` 版）；FNet3399 / Photonicat / H5000M 使用对应
  `sysupgrade` 镜像。
- 包升级：`apk update && apk upgrade`（源：`https://sources.quartzwrt.org/quartz-feed`）。
