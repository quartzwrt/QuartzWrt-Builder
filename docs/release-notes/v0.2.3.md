## 本版变更

- **第三个自有 Feed：`themes`（QuartzWrt-Themes）**：Vantage `v1.1.1` 全收（主题 + Vantage Dashboard + AP 配对）、7Dollar `v1.0.18`、Aurora `1.4.3` + Aurora 配置页。主题**不预装**，设备上 `apk add luci-theme-vantage`（或 `luci-theme-7dollar` / `luci-theme-aurora`）即可；周更同步上游，审查后进入 feed。
- **menuconfig 三层组织**：所有品牌包归 `QuartzWrt` 分类下的 `1. Base`（系统/路由）/ `2. Advanced`（蜂窝与增值网络）/ `3. Device-Specific`（风扇等设备专属）；新增 **Wi-Fi 驱动家族 meta**（mt76 / Realtek / Intel / Qualcomm / AIC8800），勾选即按家族带出驱动与固件。
- **docker 构建变体下线**：固件只出标准版；需要 docker 的设备安装可选包 **`quartz-docker`**（`apk add quartz-docker`，自动拉取 docker/dockerd/compose/dockerman，并预置 nftables 后端配方，避免 fw4「检测到旧版规则」告警）。
- **Dashboard 主题门控**：quartz 主题下显示 QuartzWrt Dashboard；安装并启用 Vantage 主题时，落地页自动切换为 Vantage Dashboard（`admin/dashboard-vantage`）。切换主题会即时刷新 LuCI 菜单（`config.change` 触发器清菜单缓存）。
- **qmodem 升级（thirdparty `a399cb2`，fork `quartz3`）**：合并上游 `550ea99`，MH5000-82M 数据接口全绑定（interface 2–6）+ 日志级别调优，模组识别与拨号稳定性提升。
- **软件源**：quartz / thirdparty / themes 三条 feed 全部签名上线；`check-feed-live` 三架构（x86_64 / rockchip / mediatek）各 5/5。
- **设备说明**：本版包含 **Ariaboard Photonicat（光影猫一代，RK3568）**；FNet3399 本轮未构建镜像（继续沿用 v0.2.2 固件，可正常使用新版软件源）。

## 使用注意

- **docker**：标准版不含 docker；`apk update && apk add quartz-docker` 安装。OTA/刷机后 rootfs 不保留可选包，需要时重新安装。
- **主题**：安装 Vantage 主题会按主题自带 postinst **切换当前主题**；如需回到 QuartzWrt 主题，在「系统 → 外观」切回 `Quartz`。
- **usb-tether**：暂未列入三层菜单，但软件源中可用（`apk add luci-app-usb-tether`），作为手机 USB 共享上网的 WAN 备援。
- 软件源 / OTA 只发标准版；docker 与第三方主题均走软件源按需安装。

## 升级

- 固件 OTA（设备）：`quartz-ota-update --check` → `quartz-ota-update --apply`（清单 usign 验签 → 镜像 sha256 → `sysupgrade` 预检）。
- 手动刷写：x86 解压后写盘（EFI 机器用 `-efi` 版）；Photonicat/H5000M 使用对应 `sysupgrade` 镜像。
- 包升级：`apk update && apk upgrade`（源：`https://sources.quartzwrt.org/quartz-feed`，索引签名由固件预置公钥校验）。
