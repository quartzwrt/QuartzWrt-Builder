# QuartzWrt v0.2.5

**构建标识（build id）**：`v0.2.5`（设备侧 `/etc/quartz-build-id`，OTA 版本比较依据）
**基座**：ImmortalWrt 25.12 @ `3682a14dd5ec`
**Feed 锁定**：quartz @ `6cab8ff1e37a`；thirdparty @ `1929b2108767`；themes @ `4028440184a9`
**签名**：apk key id `6947a869aad621cb2a8c0765c39ea104`（稳定密钥，本地/CI 产物互认）
**本版目标**：x86_64 / Erya FNet3399（RK3399）/ Ariaboard Photonicat（RK3568）/ Hiveton H5000M（MT7987A）/ **NLnet XiGuaPi V3（NL68K，RK3568）**；**只出标准版**

## 本版变更

- **新增 NL68K（西瓜皮 V3）目标**：RK3568，4GB LPDDR4X / 32GB eMMC；基座原生设备支持，无厂商补丁。
  - rootfs **8192MiB**；qmodem 5G（FM150-AE 实测）+ MT7915/MT7916 预装；ttyd 登录加固。
  - WiFi QCNFA765/QCA2066：首启自动把无效的 `country=00 / band=6g` 修为 `CN / 5G ch36 / HE80`
    （uci-defaults 顶部插入 `/etc/rc.local` + `/usr/sbin/wireless-nl68k`，`wifi down/up`）。
  - iwinfo/LuCI 无线页显示 `Qualcomm QCNFA765`（通用层 PCI ID 映射），不再显示 `Generic MAC80211`。
- **WP-16 小屏显示（仅 NL68K）**：GC9307 172×320（横屏 320×172）fbtft 驱动 + `kmod-fb-tft-gc9307`；
  `quartz-screen r9`（7 页/轮播/亮度/夜间/预览）+ `luci-app-quartz-screen r4`；
  修复速率单位 **Byte/s → bit/s**（小屏显示不再小 8 倍）；默认旋转 180°（设备层 uci-defaults）。
- **qmodem Fibocom 修复**：FM150-AE 运营商名称（`????`）、n78 带宽（100MHz）、
  Network Type（`NONE`）、ICCID 分块解析；`quartz-daemon r15` 同步带宽归一化字段。
- **累积 v0.2.4 内容**：per-device OTA、三 Feed、menuconfig 三层、Wi-Fi 驱动家族 meta、
  `quartz-docker` 可选包、Dashboard 主题门控、qmodem `quartz3`（上游 `550ea99`）。
- **OTA**：rockchip/armv8 现在有三个机型（FNet3399 / Photonicat / NL68K），共享清单 `images`
  为空（安全失败），按机型下发的 `ota/rockchip/armv8/<device>.json` 各自命中；v0.2.4 及以后
  客户端可直接 OTA。

## 使用注意

- **NL68K 首次刷写**：本版首次加入，尚无旧版 OTA 客户端；请手动下载对应
  `*-nlnet_xiguapi-v3-squashfs-sysupgrade.img.gz` 刷写。之后可走 OTA。
- **从 v0.2.4 升级**：x86_64 / FNet3399 / Photonicat / H5000M 均可
  `quartz-ota-update --check` → `--apply`（v0.2.3 及更早的 rockchip 旧客户端仍需手动刷一次）。
- **NL68K WiFi**：QCNFA765 固件/board data 走 generic BDF（`board_id 0xff`），CN 下
  160MHz/6GHz 不可用；默认 **HE80 ch36**。专用 BDF（3374 的 262/266/770）存在但当前固件未选中。
- **小屏速率**：r9 已修 Byte/s→bit/s；升级后建议复核屏幕速率显示。
- **docker**：标准版不含 docker；`apk update && apk add quartz-docker`。
- **主题**：软件源可选装 Vantage / 7Dollar / Aurora；安装 Vantage 后 Dashboard 自动切换，
  切回 Quartz 主题即恢复。

## 升级

- 固件 OTA（v0.2.4+ 设备）：`quartz-ota-update --check` → `quartz-ota-update --apply`
  （清单 usign 验签 → 镜像 sha256 → `sysupgrade` 预检）。
- 手动刷写：x86 解压后写盘（EFI 机器用 `-efi` 版）；FNet3399 / Photonicat / NL68K / H5000M
  使用对应 `sysupgrade` 镜像。
- 包升级：`apk update && apk upgrade`（源：`https://sources.quartzwrt.org/quartz-feed`）。
